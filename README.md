# Simple Notepad

Simple Notepad is a lightweight, native macOS plain-text editor
written in Objective-C using Apple's AppKit framework.

It is designed to provide a straightforward text-editing experience
without unnecessary complexity.

## Features

- Native macOS application
- Multiple independent document windows
- Create, open, edit, and save plain-text files
- Save As support
- Unsaved-changes warnings
- Undo and redo
- Word wrapping
- Printing support
- Configurable automatic text features
- Persistent text-editing preferences

## Requirements

- macOS
- Xcode for building from source

## Building from Source

1. Clone or download this repository.
2. Open `Notepad.xcodeproj` in Xcode.
3. Select the `Notepad` scheme.
4. Build and run the application.

The project uses Objective-C and Apple's native AppKit framework.
